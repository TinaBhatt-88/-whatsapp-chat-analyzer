 # WhatsApp Chat Analyzer

A Python-based WhatsApp Chat Analysis project that extracts meaningful insights from exported WhatsApp chat data. The application provides statistics, visualizations, and user activity analysis through an interactive Streamlit interface.

## Features

* Total messages, words, media, and links statistics
* Most active users analysis
* Monthly and daily activity timelines
* Activity heatmaps
* Word frequency analysis
* Emoji usage analysis
* Most common words visualization
* Interactive Streamlit dashboard

## Tech Stack

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Streamlit
* WordCloud

```text
README.md
```

## How to Run

1. Clone the repository

```bash
git clone https://github.com/TinaBhatt-88/-whatsapp-chat-analyzer.git
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run the application

```bash
streamlit run app.py
```

4. Upload a WhatsApp chat export file and explore the analysis.
